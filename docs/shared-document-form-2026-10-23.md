# 글과 자료의 글쓰기 양식 통일 · 2026.10.23.10

이전 버전은 블록 편집기만 공유하고 기존 자료의 도구 줄과 본문 높이를 따로 렌더링했다. 이번에는 긴 글과 기존 자료가 하나의 `docView(row, collection)`을 사용한다.

- 제목·본문·폴더·프로젝트·보관 용도, LIFE의 기록 종류, 저장 표시, 더보기 메뉴의 배치를 통일한다. 자료 전용 보관 설정 버튼·즐겨찾기 버튼·본문 높이는 제거한다.
- 자료실뿐 아니라 홈·전체 검색·폴더 트리·연결된 항목에서 기존 자료를 열 때도 같은 글쓰기 화면으로 이동한다. 홈의 새 자료 작성도 같은 양식을 사용한다. 짧은 입력은 명시적으로 고른 ‘링크·짧은 메모’에 남긴다.
- 공통 필드의 저장 대상은 해당 글의 원본 컬렉션으로 구분한다. 기존 `refs`를 다른 컬렉션으로 옮기거나 복제하지 않는다. 제목·본문·종류·용도·폴더·프로젝트의 편집은 필드별 자동저장·기기 임시 보관·동시 수정 검사를 사용한다.
- 기존 자료도 프로젝트와 LIFE 종류를 직접 선택할 수 있다. 프로젝트 삭제·되돌리기는 새 자료 프로젝트 연결도 함께 처리한다.
- 사진과 즐겨찾기·휴지통은 공통 더보기에서 사용한다. 삭제가 실패하거나 저장 중이면 열린 원본을 유지한다. 같은 ID의 글·자료가 있어도 지정한 원본에만 적용한다.
- 연결된 자료 화면에서 뒤로 가면 이전 기록과 임시 작성으로 돌아간다. 열린 더보기 메뉴·보관 설정은 먼저 닫고 그다음 이전 항목으로 돌아간다. 기존 빠른 입력의 임시 작성은 이어쓰기 경로로 복구한다.

## 검증

실제 앱을 Chromium과 Firebase 메모리 어댑터로 실행한다. 실제 개인 데이터에는 접근하지 않는다.

- 신규 공통 양식 8개: WORK 글·자료의 실제 필드와 본문 서식 일치, 320/390/1365px, 자료의 프로젝트·폴더·LIFE 종류 저장, 홈·검색·폴더 트리 진입과 복귀, 연결된 항목·메뉴·보관 설정의 Back 및 임시 작성, 자료 사진, 삭제 실패·미저장·같은 ID·Undo, 프로젝트 삭제·복구, 홈에서 새 자료 작성.
- 글쓰기·자료실·LIFE·공통 폴더와 신규 묶음 54개 통과. 기존 기록·연결·저장 안전성·배치·WORK 묶음 71개 통과. Back 세부·글 삭제/토글(기존 자료 WORK/LIFE)·컨테이너 회귀 10개 통과.
- 이전 빠른 입력창을 전제로 하던 테스트는 명시적인 더보기 동작으로 해당 입력창을 연다. 새 기본 흐름의 UI와 자동저장은 별도 공통 양식 테스트에서 검증한다.
- JavaScript 구문 검사, 예시 화면 생성 동기화, `git diff --check` 통과. 신규 서버·유료 서비스·데이터 일괄 변환은 추가하지 않는다.

Android 실기기와 실제 계정의 기기 간 동기화는 브라우저 모의 검증 범위 밖이다.
