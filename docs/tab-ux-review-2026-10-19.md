# 홈·프로젝트·기록 탭 사용성 점검

2026-10-19. 최신 main 12fd737의 앱을 Chromium 390×844 화면에서 확인했다. 실제 계정 대신 저장소의 Firebase 메모리 대체 모듈과 예시 데이터를 사용했다. 개인 데이터와 외부 서비스 설정은 변경하지 않았다. 실제 Android 기기·런처·동기화 장애 검증을 대체하지 않는다.

수치는 해당 뷰포트·예시 데이터의 DOM 측정값이다. 사용자 데이터 양에 따라 길이는 달라진다. 개선 제안과 실제 저장·삭제 오류를 구분해야 하며, 이번 관찰만으로 데이터 손실이나 동기화 실패가 있다고 판단하지 않는다.

## 유지할 좋은 점

- WORK/LIFE 공간 분리와 공간별 탐색이 일관된다.
- 최신 변경으로 프로젝트 핵심 메모가 위로 이동하고, 금액 표시가 정리됐다. 프로젝트 유무와 관계없이 고정 기록이 홈에 모인다.
- 프로젝트에서 작성한 기록은 해당 프로젝트 맥락을 유지한다.
- 검색 결과가 없을 때 검색어 지우기와 다른 공간 찾기를 제공한다.
- 앞선 수정으로 주요 할 일 체크 영역 확대, 입력 보존, 저장 실패 안내와 복구 경로가 마련되어 있다.

## 검토용 미리보기 — 기존 화면 유지

사용자 피드백에 따라 큰 폭으로 재구성했던 최초 시안을 교체했다. `preview.html`은 실제 `index.html`의 화면·스타일·기존 세 탭을 그대로 사용하는 독립된 예시 앱이다. `python3 scripts/build-preview.py`로 생성한다. 개선 코드는 `preview.js`와 `preview.css`, 예시 데이터는 `preview-store.js`에서 관리한다.

상단 ‘현재 구성 / 작은 개선안’으로 다음 차이만 비교한다.

- 홈: 선택한 날짜의 일정에서 같은 날짜·프로젝트로 기록 남기기.
- 프로젝트: 기존 섹션으로 스크롤하는 할 일·진행 기록·관련 글 바로가기.
- 기록: 기존 업무일지/일기·글·자료의 용도를 짧게 안내.
- 일부 작은 버튼과 선택 상자의 터치 영역 확대.

기존 메뉴, 배치, 레몬/흑백 테마, 분류, 프로젝트 구성은 유지한다. 큰 구조 변경과 주간·월간 돌아보기는 이 시안에서 제외했다. 실제 앱의 `index.html`은 이번 피드백 대응에서 변경하지 않았다.

독립된 메모리 데이터베이스를 사용하며 로그인과 Firebase, 네이티브 Android 연결을 시작하지 않는다. 입력과 환경설정은 메모리에만 보관하며 실제 앱의 localStorage를 읽거나 쓰지 않는다. 새로고침하면 예시 데이터로 돌아간다. 불러오지 못할 때 재시도 안내를 제공한다.

확인: 실제 Pages와 같은 `/Arecmik/` 경로에서 세 탭·비교 토글·일정 날짜/프로젝트를 이어받는 기록 작성/저장·프로젝트 바로가기·WORK/LIFE 분리·새로고침 초기화·실제 앱 localStorage 미변경을 확인했다. 360·390·768·1365px에서 가로 넘침, JS 오류, 외부 서비스 요청과 HTTP 오류가 없었다. 모바일 화면 캡처로 원래 앱과 같은 배치를 확인했다. 실물 휴대폰 검증을 대체하지 않는다.
