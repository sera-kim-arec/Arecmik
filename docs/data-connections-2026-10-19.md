# 데이터 연결 — 2026.10.19.2

화면의 홈·프로젝트·기록 구성과 레몬/흑백 테마를 유지하면서, 서로 다른 종류의 항목 사이를 원본으로 연결한다. 새 서버, 새 외부 서비스, 새 Firestore 컬렉션은 추가하지 않는다.

## 사용 흐름

1. 선택한 날짜의 일정 또는 일정 상세에서 기록을 남긴다. 일정 날짜·프로젝트를 이어받으며, 새 기록과 원래 일정은 서로 연결된다.
2. 기록·글·업무일지/일기·자료·프로젝트·업체·비용·잊지 말 것 메모에서 후속 할 일을 만든다. 원본에 속한 프로젝트, 또는 직접 연결한 프로젝트가 하나라면 기본 선택한다. 변경도 가능하다.
3. 날짜를 지정하면 기존 달력에, 비우면 기존 날짜 없는 할 일에 표시한다. 연결된 곳에서 완료 체크를 해도 원래 할 일의 상태가 바뀐다.
4. 기존 항목 연결에서 같은 공간의 원본을 검색해 연결한다. 제목·내용을 수정하면 연결 화면도 최신 원본을 보여준다. 연결 이름도 통합 검색에 포함하고, 프로젝트에 직접 연결한 자료를 보관함의 프로젝트 필터로 찾을 수 있다.
5. 기존 프로젝트·업체·할 일별 비용 관계와 일지의 같은 날 항목은 자동으로 함께 보여준다. 비용 합계는 기존 소속 기준을 유지하여 참고 링크 때문에 중복 합산하지 않는다.

## 저장과 호환

선택적 `connections` 배열을 기존 문서에 추가한다. 연결 항목은 `{c, id, day?, sourceId, sourceDay?}` 형태다. `day`와 `sourceDay`로 월 단위 일지 안의 개별 날짜를 구분한다. 날짜별로 내용을 복사하거나 일지를 새 구조로 이관하지 않는다.

두 원본의 존재와 공간을 확인하고 연결·해제를 Firestore 트랜잭션 하나로 저장한다. 기록/후속 할 일 생성도 원본 연결과 함께 원자적으로 저장한다. 동시 수정 시 최신 연결 배열을 읽으며, 본문과 다른 필드를 덮어쓰지 않는다. 오프라인 등으로 트랜잭션이 실패하면 입력을 유지하고 재시도를 허용한다.

삭제된 대상은 연결 화면에서 숨기고, 휴지통 복구 시 원래 ID로 다시 연결된다. 백업 형식은 기존 버전 1을 유지하며 연결 필드를 함께 보관한다. 프로젝트 소속과 참고 연결을 분리해서 여러 프로젝트가 같은 원본을 참고할 수 있다.

다음 반복 일정에는 이전 회차의 기록 연결을 복사하지 않는다. 네이티브 위젯이 선택적 필드를 복사하더라도 `sourceId`가 새 회차 ID와 다르면 그 연결은 표시하지 않는다. Android 위젯의 저장 방식과 외부 로그인은 변경하지 않았다.

## 조작과 데이터 보존

기존 상세 화면에 작은 연결 영역을 추가한다. 연결 선택·후속 할 일 작성은 별도 다이얼로그로 열어 원래 편집 중인 값을 유지한다. 뒤로 가면 원본 화면·검색어·임시 입력을 복구한다. 저장 중 중복 제출을 막으며 연결 해제는 원본 내용을 지우지 않는다. 목록은 나누어 표시하고 검색으로 좁힐 수 있다.

미리보기는 같은 실제 화면 코드를 사용하되 로그인·네이티브 연결·서비스 워커 등록을 시작하지 않는다. 입력, 연결, 설정은 메모리에만 저장하며 실제 앱의 localStorage에 접근하지 않는다. 상단에 예시 데이터와 새로고침 초기화를 명시하고 실제 앱 링크를 제공한다.
