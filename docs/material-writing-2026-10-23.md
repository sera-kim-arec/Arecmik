# 자료도 글처럼 작성 · 2026.10.23.9

- 자료실의 기본 버튼은 ‘자료 쓰기’다. 기존 긴 글 편집기로 넓게 작성하고 자동저장하며, 현재 자료실 폴더와 자료 용도를 이어받는다. 링크·짧은 메모 입력은 작성 버튼 옆 메뉴에 남긴다.
- 기존 자료(`refs`)도 자료실 목록에서 열면 넓은 글 화면에서 제목·본문·폴더·용도를 자동저장한다. 제목·목록·토글·사진·문단 이동은 기존 블록 편집기를 공유한다. 기존 자료의 컬렉션·ID·관계·즐겨찾기를 유지한다.
- `docCollection`으로 긴 글과 기존 자료를 구분하여 같은 ID가 있어도 편집·연결·브라우저 뒤로 가기가 다른 원본을 가리키지 않게 했다. 기존 검색·홈·연결 항목의 빠른 자료 입력 경로는 유지한다.
- 기존 자료의 ‘보관 설정’에서 공간 변경·휴지통 이동을 계속 사용할 수 있다. 넓은 화면의 편집이 저장 중이면 설정창 편집과 겹치지 않게 하며, 저장하지 못한 편집은 복구 경로로 안내한다. 이전 빠른 입력창의 임시 작성은 넓은 화면의 ‘이어쓰기’로 열어 원래 충돌 검사 후 저장한다.
- 목록 옆 노란 책등 장식과 종류별 색 사각형은 제거했다. 제목·요약·날짜·폴더와 즐겨찾기로 목록을 읽는다.
- 새 글 생성 실패는 현재 목록과 안내를 유지하고 연속 클릭으로 중복 생성하지 않는다. 계정이 바뀐 뒤 생성 응답이 도착하면 다른 계정의 화면에 원본을 삽입하지 않는다.

## 검증

Firebase 메모리 어댑터로 Chromium에서 검증하며 실제 계정 데이터에 접근하지 않는다.

- 신규 `test_material_writing.py` 12개 통과: 기본 자료 글 작성, 기존 자료 원본·관계 보존, 토글·Undo, 관련 기록 열기와 뒤로 가기, 저장 충돌·실패·재시도, 다른 필드 보존과 폴더 충돌, 컬렉션 간 ID 중복, 이전 임시 작성 이어쓰기, 설정 전 저장 완료, 생성 실패·연속 클릭, 320/390/1365px 화면과 44px 조작 및 장식 제거.
- 자료실·LIFE·신규 편집 흐름 묶음 33개 통과 후, 신규 편집 최종 12개를 재검증했다. 기존 연결·저장 안전성 41개 통과. 기록·공통 폴더·배치 회귀도 검증했다. 초기 연결 회귀에서 기존 연결 항목 열기까지 넓은 화면으로 바뀐 것을 확인하여 해당 빠른 입력 경로를 유지하도록 수정하고 연결 묶음을 다시 통과했다.
- `index.html` 모듈·`connections-ui.js` 구문 검사, 생성 미리보기 동기화, `git diff --check` 통과.

별도 서버·유료 서비스·데이터 이동은 추가하지 않는다. 실제 Android 기기와 사용자 계정의 기기 간 동기화는 모의 브라우저 검증 범위 밖이다.
