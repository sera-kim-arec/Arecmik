# 화면 정돈 미리보기 · 2026-10-21

[인터랙티브 미리보기](https://sera-kim-arec.github.io/Arecmik/preview.html?v=202610211)에서 상단 **기존 화면 / 정돈한 화면**을 번갈아 비교할 수 있습니다. 하단 홈·프로젝트·기록 탭, WORK/LIFE, 날짜 선택과 원래 편집 기능을 직접 사용합니다.

이 페이지는 예시 데이터만 사용하는 독립 미리보기입니다. 로그인·Firebase·Android 연결을 시작하지 않으며 실제 앱의 저장소를 읽거나 쓰지 않습니다. 예시에서 수정한 내용은 새로고침하면 초기화됩니다. 실제 앱 화면과 데이터는 이번 제안으로 변경하지 않았습니다.

## 제안한 변화

- 홈: 월 달력과 선택일의 일정·할 일을 먼저 보고, 날짜 없는 할 일·오늘 일지·메모와 자료는 펼쳐서 봅니다. 밀린 할 일이 있으면 해당 구역은 처음부터 펼칩니다.
- 프로젝트: 핵심 메모와 다음 일정·할 일을 먼저 보여 줍니다. 지급액·예산은 상단에 남기고 비용 내역·업체·타임라인·진행 기록·관련 기록은 펼쳐서 봅니다. 모바일은 핵심 메모가 할 일보다 위에 옵니다.
- 기록: 검색과 날짜순 목록을 강조합니다. 즐겨찾기는 바로 누를 수 있으며 종류·월·프로젝트 필터는 펼쳐서 사용합니다. 적용된 조건 수와 필터 초기화를 제공합니다.
- 공통: 크림 바탕과 레몬색 선택 표시, 진회색 글자로 대비를 정리했습니다. 제목·본문·보조 설명의 크기와 구역 사이 간격을 맞췄습니다. 흑백 테마도 기존 선택 경로로 볼 수 있습니다.

## 검토할 질문

1. 접어 둔 정보 중 바로 보여야 할 것은 무엇인가요?
2. 홈에서 날짜 확인 → 일정 열기 → 기록 남기기가 자연스럽게 이어지나요?
3. 프로젝트에서 가장 중요한 다음 행동이 분명한가요?
4. 기록을 검색하거나 조건을 좁혀 찾는 경로가 발견하기 쉬운가요?
5. 크기·색상·여백이 구분에 도움이 되나요? 기존보다 길을 잃는 곳은 없나요?

## 검증 범위

Chromium에서 실제 Pages와 같은 `/Arecmik/` 경로로 확인했습니다. 두 비교 모드 × 320·360·390·768·1365px × 세 탭의 30가지 조합과 프로젝트 상세의 모든 접힌 구역을 검사했습니다. 날짜 선택·완료 체크·메모 자동 저장·진행 기록 추가·기록 작성·검색·즐겨찾기·필터가 작동하고, 비교 모드를 전환해도 예시 내용과 펼침 상태가 유지됩니다. 새로고침 초기화·실제 localStorage 미변경·외부 요청 없음도 확인했습니다. 실제 Android 기기에서의 사용성 검증은 포함하지 않습니다.

`preview.js`·`preview.css`에서 제안을 조정하고 `python3 scripts/build-preview.py`로 재생성합니다. 실제 앱 반영 여부는 이 미리보기를 사용해 본 뒤 결정합니다.
