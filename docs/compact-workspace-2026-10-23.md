# 일정·할 일 목록과 문단 이동 다듬기

버전: `2026.10.23.5`.

사용자가 제공한 두 번째 약 55초의 Notion 영상을 참고했다. 한 문단에 있는 두 줄이 함께 이동하고, 빈 문단을 사이에 두고 다시 배치되는 흐름을 재현했다. 문단을 끌 때 보이는 미리보기도 줄바꿈을 유지한다. 위치 표시선, 놓은 문단의 선택 표시, 실행 취소와 재열기 후의 구조를 확인한다.

## 공간을 줄인 부분

- 월 달력의 일정·할 일은 작은 배경 카드 대신 한 줄로 표시한다. 시간과 프로젝트 색은 유지한다. 날짜를 선택해도 최대 3개까지만 달력 안에 표시한다.
- PC의 `+N개 더`는 해당 날짜의 전체 목록을 열고 목록으로 포커스를 옮긴다. 모바일에서는 날짜 칸을 눌러 전체 목록을 확인하며, 항목이 많은 날짜는 개수를 함께 표시한다.
- 선택한 날짜의 전체 목록, 미룬 일·날짜 없는 일, 프로젝트의 할 일에서 반복 구분선과 안쪽 여백을 줄인다. 메모 미리보기는 한 줄이고 본문은 상세에서 읽고 수정한다.
- 날짜 없는 할 일 입력과 일정 만들기는 같은 줄에 둔다. 기본 3일·7일·2주 보기의 빈 날짜 최소 높이를 줄이고, 선택한 날짜는 머리글로 표시한다.
- 모바일 완료 체크 영역은 44px 이상을 유지한다. 날짜나 완료 여부, 프로젝트 연결, 저장 경로는 화면을 정리하기 위해 변환하지 않는다.

## 확인 방법

- `tests/test_compact_calendar.py`: 바쁜 날의 월 달력 높이, 전체 목록 접근, 마지막 항목 수정·완료·재열기, 모바일 완료 체크 크기와 가로 넘침, 날짜에 일정 추가.
- `tests/test_block_moving.py`: 두 줄을 포함한 문단을 빈 문단 너머로 끌어 옮기기, 이동 중 원본을 저장하지 않기, 줄바꿈을 보여 주는 미리보기, 실행 취소·다시 실행·저장 후 재열기. 기존 마우스·터치 이동 검사도 함께 실행한다.
- 예시 데이터로 PC 1365px, 모바일 390px의 월 달력·3일·프로젝트 화면을 비교한다. 비교 캡처와 측정치는 별도 작업 산출물이며 개인 영상은 저장소에 넣지 않는다.
- 320~1920px의 홈·프로젝트·기록과 펼친 프로젝트를 확인하고, 미리보기의 데이터 격리와 읽기만 할 때 데이터가 바뀌지 않는지 확인한다.

일정 10개를 포함한 동일한 예시 데이터의 PC 월 달력은 860.2px에서 534.7px로 줄었다. 프로젝트 할 일 영역은 821px에서 694px로 줄었다. 이 수치는 해당 예시 데이터와 화면 폭에서 측정한 것이며 실제 일정 수와 제목 길이에 따라 달라진다.

## 하위 폴더 생성 수정

기존 폴더 트리는 `fid`를 읽지만, 새 폴더 생성은 항상 `fid: ''`로 최상위에 저장했다. 생성 양식에 만들 위치를 표시하고 선택한 폴더를 기본 상위 폴더로 사용한다. 폴더 관리에서도 특정 폴더 안에 만들 수 있다. 상위 폴더 존재 여부와 WORK/LIFE 일치는 트랜잭션에서 확인한다. 저장 실패 시 이름과 위치를 남기고, 중복 제출은 막는다.

하위 폴더는 글 목록의 본문에도 표시하며, 상위 폴더로 돌아가는 버튼과 전체 경로를 제공한다. 모바일에서 모든 폴더가 한 겹의 칩으로 펼쳐지던 방식 대신 실제 폴더 안으로 들어가도록 했다. 글의 폴더 선택에도 전체 경로를 표시한다. 폴더 삭제 시 글과 하위 폴더를 상위로 이동시키는 기존 처리는 유지한다.

사용자가 설명한 장기 방향은 기록과 자료가 공존하는 개인 아카이브다. LIFE는 일상·스크랩·독서·영화 기록, WORK는 업무 정보와 재사용할 자료가 중심이다. 글·참고 링크·캡처뿐 아니라 PDF·엑셀·워드 등의 파일도 같은 주제/프로젝트 아래에서 찾을 수 있기를 원한다. 현재 이미지 첨부와 링크·글 보관은 지원하지만, 일반 파일의 직접 첨부·동기화는 이번 변경에 포함하지 않는다. 자료함 확장은 기록을 모두 자동 수집하는 방식이 아니라 사용자가 보관한 자료를 폴더·검색·프로젝트에서 찾는 방향으로 검토한다. LIFE와 WORK의 기존 기록을 옮기거나 새 분류를 강제로 적용하지 않는다.

## 검증 결과

- 일정·편집기 수정 후 전체 307개 검사 통과.
- 이후 추가한 하위 폴더 시나리오 5개 및 관련 폴더 삭제·레이아웃·기록 검사 29개 통과. 하위 폴더의 글 저장·재열기, 삭제된 상위 폴더 처리, 실패 재시도, 중복 제출 방지, 모바일 탐색과 취소를 포함한다.
- 최종 상태에서 바쁜 달력 검사 3개와 320~1920px 화면·미리보기 격리 검사를 확인했다. 하위 폴더 목록·생성·관리 화면은 320/390/1365px에서 확인했다. 독립 미리보기에서 새 폴더를 만들 수 있고 새로고침하면 예시 상태로 초기화된다.
- 모바일 완료 체크의 44px 조작 영역에 불필요하게 나타나던 바깥 테두리를 없앴다. 실제 체크 표시는 작은 크기로 남는다.
